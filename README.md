# Stock Market Simulator Backend

Backend API for the Stock Market Simulator. It handles user data, stock transactions, portfolio management, and database operations.

## Features

* REST API for the stock market simulator
* User and portfolio management
* Buy and sell stock operations
* Database integration
* API request handling and validation

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* JavaScript
* 
## Environment Variables

Create a `.env` file in the backend directory and add the required configuration:

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```

## API

The backend provides REST API endpoints used by the frontend for managing users, stocks, transactions, and portfolios.
